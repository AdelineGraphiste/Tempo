# Vérifications avant mise en ligne

La compilation a été exécutée depuis ce dossier avec restauration des dépendances et vérification SHA-256.
Le résultat inclut l’application, le MSI et le désinstalleur.

La distribution actuelle est conservée dans release/Tempo-Windows.zip.
Les données de test, calendriers, historiques et caches locaux sont exclus du projet.

Lors de la publication, le README sera la page d’accueil du dépôt. Le ZIP utilisateur pourra être joint à une GitHub Release.
Le dépôt cible et sa visibilité seront choisis lors de cette étape.
